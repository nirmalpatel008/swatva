Scan a file in your browser

Choose an Excel, CSV or SQLite file. Swatva checks it for personal data and shows you the report right here, with every value masked.

Your file never leaves this computer. It is read by your browser and scanned on this page, and nothing is uploaded. The first scan downloads Swatva’s code (about 10 MB) and then runs offline.

No file handy? Download the sample to look at it first

Good to know

  • This page runs the same scanner as the command line tool. For whole folders, very large files or regular use, install it on your computer.
  • Swatva reads a sample of up to 1,000 rows per sheet or table.
  • Old .xls files aren’t supported yet. Open them in Excel and use Save As to make an .xlsx.
  • The report shows where personal data appears to be. It helps you prepare for the DPDP Act and is not legal advice.
